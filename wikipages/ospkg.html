O que é e como funciona

O OSpkg é um gerenciador de pacotes escrito em C que funciona como um roteador de comandos. Ele valida os argumentos passados pelo terminal e dispara a execução de scripts em Bash estruturados dentro do diretório padrão do sistema (/usr/share/ospkg).

Detalhes de Funcionamento (ospkg.c)

  • Validação de Argumentos: Verifica se os parâmetros necessários foram informados. Caso contrário, exibe o painel de uso (show_usage) e encerra a execução.
  • Checagem de Arquivos (file_exists): Utiliza a função access() com a flag F_OK para garantir que o script de destino realmente existe antes de tentar rodá-lo.
  • Execução de Scripts (execute_script): Formata o comando bash num buffer seguro e utiliza system(), retornando o código de saída exato via WEXITSTATUS().
  • Mapeamento de Comandos:
    • update: Executa o script mestre de atualização localizado em /usr/share/ospkg/update/update.sh.
    • install <pacote>: Se for um arquivo .sh direto existente no disco, executa-o. Caso contrário, busca e executa a receita em /usr/share/ospkg/receita/<pacote>.sh.
    • uninstall <pacote>: Executa o script de desinstalação em /usr/share/ospkg/app-uninstall/<pacote>.sh.

Uso

  ospkg install <pacote|caminho/script.sh>
  ospkg uninstall <pacote|caminho/script.sh>
  ospkg update
