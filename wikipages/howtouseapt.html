Como usar o APT - Tutoriais

O APT é um gerenciador de pacotes de distros Debian/Ubuntu, que é a base do OxyohanOS, sendo extremamente facil e simples de usar. Veja como:

Atualizar os repositórios

Antes de atualizar o OxyohanOS, saiba que o apt OxyohanOS funciona assim:
O OxyohanOS baixa os pacotes via repositórios do Debian e do Oxyohan para instalá-los em sua máquina e para atualizar o sistema e os apps nele, primeiro tem que atualizar eles para eles não estarem desatualizados, senão o sistema fica desatualizado

Usa-se o comando:

    sudo apt update

Atualizar o OxyohanOS

Agora que você aprendeu à atualizar os repositórios (ou repos), você pode atualizar o sistema usando:

    sudo apt upgrade

Baixar um app com o APT

Para baixar um app usando o APT, você coloca:

    sudo apt install (pacote)
    Substitua o (pacote) pelo app que deseja instalar

Remover um app com o APT

Para remove um app usando o APT, você coloca:

    sudo apt remove (pacote)
    Substitua o (pacote) pelo app que deseja instalar

Como recuperar uma instalação crashada

Se uma instalação de pacote deu erro, use o parametro --fix-broken para conserta-la

    sudo apt --fix-broken
